# 割り勘計算Webアプリ

グループ旅行や飲み会など、複数人で費用を分担する場面で使える割り勘計算Webアプリ。
各メンバーの立て替え金額を入力すると、支払い回数が最小になる精算方法を自動計算します。

## デモ

**GitHub Pages:** `https://<username>.github.io/<repo-name>/`

## 使い方

1. **メンバー追加** — 参加者の名前を入力して追加する
2. **支出入力** — 誰がいくら何に使ったかを記録する（対象者を選択可能）
3. **精算計算** — 「精算する」ボタンを押すと「誰が誰にいくら払うか」を最小回数で表示

## ローカルで動かす方法

ビルド不要。`index.html` をブラウザで直接開くだけで動作します。

```
# ファイルをダウンロードまたはクローンして
open index.html
```

## 技術スタック

- バニラ HTML / CSS / JavaScript
- ビルドツール・フレームワーク不要
- バックエンド不要（すべてブラウザ内で完結）
